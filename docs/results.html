Testing and verification

Test the rules and the running service.

The automated suite covers source-backed undergraduate and postgraduate rules, catalogue-only results, discipline filtering, MSCE grade boundaries, incomplete profiles, GPA validation, API behavior, and a live Waitress request. Run the suite locally for the current result; test outcomes are not evidence that an institution will admit an applicant.

Unit

MSCE 1–9 and credit thresholds, programme-specific subject rules, discipline validation, alternative postgraduate routes, unknown classifications, and invalid profiles.

Integration

HTML and health routes, source-attributed matches for both levels, discipline-filtered results, invalid JSON, unsupported content type, and explicit API errors.

System

Start Waitress as a subprocess, wait for readiness, submit a real HTTP request, verify the programme-level result, and stop the process.

Run the checks

From the project directory run py -m unittest discover -s tests -v. See the project README for setup instructions.

Scope: Passing tests verify implementation behavior and fixture rules, not applicant selection or the future availability of an intake.
