Methodology

Policy in. Explanation out.

The browser evaluates profiles locally against the source-attributed catalogue embedded when the page loads. The JSON API uses the same Python policy. Undergraduate checks count MSCE grades 1–6 as credits, enforce subject combinations and apply stricter subject-grade limits only where stated by the programme source. Missing grades are not silently treated as failures unless the applicant confirms the full result set is entered.

For postgraduate programmes, each documented admission route is evaluated independently. A programme is marked eligible if at least one route is met, not eligible if all routes fail, and more information needed if any route could still be met with missing information. GPA is collected on a 0–5 scale but is informational only; no GPA-to-classification conversion is inferred.

Students first choose a discipline or faculty and may narrow suggestions by degree level; the interface does not present the entire catalogue as an unrestricted browse list. Listings without verified entry criteria are marked as not assessed; they are never treated as eligible or ineligible. Catalogue coverage is partial and is not a substitute for checking current NCHE accreditation and institutional admissions information. DMI St. John the Baptist University is linked, but its supplied official domain could not be resolved during verification, so its programmes are not guessed.

1 · Validate

Accept only MSCE grades 1–9 and postgraduate profile values within the declared range. Reject malformed input with an explicit error.

2 · Match

Compare the profile with the selected level's official programme rules, including alternative entry paths and experience requirements.

3 · Explain

Return a status and rule trace for each programme, together with the programme page and intake source.

Sources, limitations, and privacy

Representative sources include KUHeS MBBS, MUST Medical Microbiology, MUBAS programmes, UNIMA undergraduate programmes, LUANAR undergraduate programmes, and UNILIA undergraduate programmes. Eligibility criteria are in `config/admission_policy.json`; catalogue-only listings are in `config/program_catalog.json`.

Intake information differs by institution and may change. The matcher cannot assess competitive selection, recognition decisions, document authenticity, interviews, or requirements not stated in the cited pages. A result is guidance only; applicants should confirm current requirements with admissions offices. Candidate data is evaluated in the browser and is not stored.
